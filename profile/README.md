# K-OSSC

**한국 오픈소스 보안 커뮤니티** · Korea Open Source Security Community

소프트웨어 공급망 보안을 공부하고, 쓰고, 옮기는 사람들이 모인 곳입니다.
2025년 8월 첫 모임으로 시작했고, 2026년 8월 커뮤니티 서버와 이 조직을 열었습니다.

---

## 무엇을 하나

**Community** — 디스코드 서버에서 매일 이야기하고, 정기 밋업으로 만납니다.
2026년 8월 제1회 SOSS 밋업을 열었습니다.

**Education** — 공급망 보안을 처음 보는 사람도 따라올 수 있는 글과 자료를 만듭니다.

**Localization** — 해외 표준과 도구 문서를 우리말로 옮깁니다. 옮기는 데서 그치지 않고,
한국 현장에 맞는 실증을 붙이는 것까지가 목표입니다.

## 여기 올라오는 것

| 리포 | 내용 | 상태 |
|---|---|---|
| `supply-chain-notes` | 공급망 보안 연재. 디스코드 게시물의 원본과 수정 이력 | 준비 중 |
| `sbom-playbook` | SIG-SBOM이 함께 만드는 SBOM 실무 안내서 한국판 | 예정 |

## 우리가 일하는 방식

> **익명으로 읽고 실명으로 말한다.**
> 서버는 누구나 들어와 읽을 수 있습니다. 다만 전문가로서 하는 말에는 이름을 답니다.

> **AI가 초벌하고 실명이 검수한다.**
> 번역과 초안에 AI를 씁니다. 대신 사람이 반드시 확인하고, 확인한 사람의 이름을 남깁니다.
> 실제로 미국 행정명령 14028의 `rescind`를 '폐지'로 옮긴 초벌을 검수에서 '철회'로
> 바로잡은 적이 있습니다. 점검 도구를 점검하는 일이 우리 몫이라고 생각합니다.

**K-OSSC (Korea Open Source Security Community)** is a volunteer community
working on software supply chain security in Korea.

We run a Discord server, hold regular meetups, publish writing on SBOM and
supply chain security, and translate international standards and tool
documentation into Korean.

Our work rests on three pillars: **Community, Education, and Localization.**
We use AI for first drafts and translation, but every piece is reviewed by a
named human before it ships.

Founded August 2025. GitHub organization opened August 2026.
Advised by Allan Friedman (IST). Led by Yunseong Choi, OpenSSF Ambassador.

Come say hello on Discord: **[invite link](https://discord.gg/RupAuPJwDA)**
